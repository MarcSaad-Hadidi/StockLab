# Boosted training on relative stock return ranks

The two fixed purchase priorities on eight stocks earn more than 20% annualized on the complete backtest. With fresh capital from January 2024 through the latest verified November 25 close, the DCA priority earns 16.51% against SPY's 16.73%. Test whether a new learned ranking improves which original HGBT buys receive capital. The earlier binary SPY-outperformance event used five training stocks and a fixed threshold to trigger buys and sales. This study uses the archived 111-identity learning panel, a bounded rank target and the same original buy and quarter-sale signals. ## Portfolio comparison

- **Learned priority** preserves every original BUY intention. Within each confirmed DCA priority band, order simultaneous BUYs by the new rank score, then ticker.
- **Learned half** uses that ordering and retains an original BUY only when its score ranks among the top four of the eight observable stocks at that close. Ties use ascending ticker.
- **Strength half** applies the same top-four selection and DCA ranking with trailing 252-session relative strength serving as the score instead.
- **Binary priority** uses the matched binary classifier's score for ordering within DCA bands and preserves every original BUY intention.
